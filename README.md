# Personality Portal · Insight Pro

個人探索與職涯對話工具。沿用原有完整問卷架構，整合日常處事的三個問題、完整專項 AI 提示詞、人工核對及報告匯出。

正式網址：<https://koraner.github.io/Personality-Portal-Insight-Pro/>

## 這一版提供什麼

- 暖色系動態首頁、結果總覽與收合的進階工具，支援桌面與行動版面。
- 原有八組問卷，以及「承諾與責任、發現疏漏、意見不同」三個主題。
- 原有完整專項分析提示詞，加上匿名化、不補猜及作答證據規則。
- 複製一份提示詞至外部 AI；貼回一份回答，同時載入完整報告與由全文提煉的三段精簡回饋。
- 完整 PDF、報告 TXT、Obsidian 筆記文字，以及收合的 Markdown 匯出工具。
- 保留輸入 `2222` 的虛構示範；首頁不顯示示範代碼提示。

## 使用方式

1. 邀請者進入工作台，選擇問卷模組並產生評測連結。
2. 受測者開啟連結完成問卷，將結果代碼交給邀請者。
3. 邀請者在工作台讀取結果，複製提示詞至自己選擇的 AI。
4. 貼回 AI 回答，核對完整報告與精簡回饋，下載 PDF 或文字保存。

工作台入口沿用原版操作：點擊頂部品牌名稱五次。首次使用時，自行設定至少六個字元的工作台密碼；之後在同一瀏覽器輸入自己設定的密碼。只在此瀏覽器保存加鹽雜湊，不含任何公開預設密碼。這個門檻不是雲端帳號驗證，也無法保護已交付的結果代碼。換裝置或清除網站儲存後，需重新設定。

## GitHub Pages 版的保存方式

這是公開可開啟、在使用者瀏覽器運作的靜態網站。頁面不會自動呼叫 AI、不會將作答上傳 GitHub，也不會連線 Windows 私人預覽資料庫。

問卷作答草稿保存在同一瀏覽器；結果透過代碼人工交付。結果代碼可能含個人資料，請只交給指定邀請者；需要保護時使用原有的結果代碼加密功能。

完整 AI 報告、精簡回饋及人工筆記請在關閉或重新整理前下載保存；本版不提供雲端同步或分析草稿自動還原。匯出的完整 PDF 與筆記可能包含內部資料，交付前請確認內容。

集中保存、跨裝置管理及可收回的回饋查詢連結屬於另外的伺服器版本，GitHub Pages 版未啟用這些功能。評測及 AI 解讀供探索與對話，不是心理診斷，也不作為單一決策依據。

## 原始碼與重建

`index.html` 是已打包完成、可直接開啟的正式頁面。`src/` 保存完整可編輯原始碼及原始題庫；不包含客戶資料、資料庫或服務憑證。

使用 Node.js 與 npm 安裝鎖定版本的套件後重建：

```sh
npm ci
npm run build
```

建置會更新根目錄 `index.html`。GitHub Pages 沿用 `main` 分支根目錄發布；`.nojekyll` 讓檔案直接靜態提供。每次更新保留 Git 歷史，可回復至先前版本。

原始版本保留在 [更新前的 Git 歷史](https://github.com/koraner/Personality-Portal-Insight-Pro/blob/30592bda98ed9638b87bde05c5e827d0fae6fd4e/index.html)，不另外重新發布含舊示範身分的檔案。可編輯原始碼中的示範身分已明確標為虛構。既有第三方字體檔保留以免破壞舊連結，新版首頁不載入該字體。
